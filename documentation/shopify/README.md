# Shopify Developers guide

We need to become a shopify partner

Shopify is an ecommerce platform that allows users to create an online presence for their business.

## Shopify Developers Platform

Shopify provides a platform for developers to build applications and integrations that enhance the Shopify experience. This includes building custom themes, apps, and integrations with other services.

Shopify development can be categorized into 3 categories:

- Shopify App Development: This allows developers to extend the core functionality of Shopify

- Shopify Theme Development: This allows developers to create custom themes for Shopify stores

- Storefront development: Allows development of custom storefronts that are hosted outside of Shopify. This is done using the Storefront API and the Shopify CLI. This is a more advanced topic and requires a good understanding of web development and APIs.
